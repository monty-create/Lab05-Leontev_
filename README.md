# Практическая работа №5. Продвинутый switch

## Цель работы
Изучить расширенные возможности оператора `switch` и синтаксиса `switch expression` в современном языке C#, научиться использовать логические паттерны `or`, `and`, `not`, а также настраивать контекстные фильтры с помощью ключевого слова `when`.

## ПР5. Ответы на контрольные вопросы по конструкциям

### 1. Как работают логические шаблоны or и and в блоках case?
Использование ключевых слов `or` и `and` внутри блоков `switch` позволяет значительно упростить проверку составных условий. 
- Шаблон `or` группирует схожие ветки выполнения, заменяя громоздкие повторения (например, проверка выходных дней или дней недели в Варианте 3 через `"понедельник" or "вторник" or ...`).
- Шаблон `and` эффективно проверяет попадание числовой переменной в заданный диапазон значений (как при проверке баллов `case >= 40 and <= 59`) без необходимости повторно писать имя переменной.

### 2. В чём преимущество синтаксиса switch expression перед классической конструкцией?
В отличие от классического оператора, синтаксис `switch expression` возвращает вычисленное значение напрямую в переменную (как это сделано при определении `tempCategory`, `season` или `ageGroup`). Этот подход убирает из кода избыточные и повторяющиеся ключевые слова `case` и `break`, делая логику программы компактной и лаконичной (используется стрелочный формат `=>`). Роль ветки `default` здесь выполняет символ нижнего подчеркивания `_`.

### 3. Что такое упорядоченные диапазоны в switch expression и в каком порядке они проверяются?
Упорядоченные диапазоны позволяют проверять числовые условия последовательно. В C# они всегда проверяются компилятором строго сверху вниз. Это наглядно доказано в Задачах А и Б (для месяцев и возраста), а также в блоке температур. Благодаря этому порядку нет необходимости писать сложные диапазоны с `and` на каждой строчке — достаточно указывать последовательные ограничения по возрастанию (`<= 6`, `<= 17`, `<= 64`), и программа сама перехватит нужное значение.

### 4. Для чего используется модификатор условий when в блоках case?
Модификатор `when` позволяет задавать гибкие дополнительные условия для конкретной ветки выполнения, основываясь на значениях других независимых переменных. В коде это помогло разделить логику для совершеннолетних посетителей: ветка `case >= 18 when hasTicket` сработает только в том случае, если у пользователя есть билет, а обычный `case >= 18` перехватит тех, у кого билета не оказалось, выдав сообщение "Нет билета".

### 5. Как работает инструкция goto case и в каких случаях её применяют?
Инструкция `goto case` позволяет принудительно передать управление из текущего блока `case` в любой другой выбранный блок внутри этой же конструкции `switch`. В коде при значении `level = 2` программа успешно вывела "Средний уровень", а затем с помощью `goto case 1` автоматически перешла на выполнение инструкций из первой ветки, проигнорировав стандартное ограничение `break`. Это полезно для построения сквозной иерархической логики.
